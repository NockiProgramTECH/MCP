Politique de confidentialité

Dernière mise à jour : 30 septembre 2026

1. Introduction

La présente politique de confidentialité décrit comment le serveur OpenClaw MCP (ci-après le « Service ») traite les informations lorsque vous l'utilisez. Nous nous engageons à protéger votre vie privée et vos données.

2. Données collectées

Le Service ne collecte, ne stocke et ne transmet aucune donnée personnelle à des fins propres.

Le Service agit comme un intermédiaire (proxy) entre un agent IA et des API tierces. Les seules données qui transitent sont :

  • Les requêtes envoyées aux API tierces (GitHub, LinkedIn, Meta, TikTok).
  • Les réponses retournées par ces API.
  • Les tokens d'accès fournis par l'utilisateur via des variables d'environnement.

3. Tokens d'accès

Aspect Détail
Stockage Les tokens ne sont jamais stockés en base de données ni sur disque par le Service.
Transmission Les tokens sont transmis uniquement aux API tierces concernées, via HTTPS.
Journalisation Les tokens ne sont jamais écrits dans les logs du Service.
Réponses Les tokens ne sont jamais inclus dans les réponses MCP retournées à l'agent IA.

4. Services tiers

Lorsque vous utilisez le Service pour interagir avec des API tierces, vos données sont soumises aux politiques de confidentialité de ces services :

  • Politique de confidentialité de GitHub
  • Politique de confidentialité de LinkedIn
  • Politique de confidentialité de Meta
  • Politique de confidentialité de TikTok

5. Journalisation (Logs)

Le Service peut générer des logs techniques à des fins de débogage. Ces logs :

  • Ne contiennent jamais de tokens d'accès ou de secrets.
  • Peuvent contenir des métadonnées de requêtes (endpoints appelés, codes de statut HTTP).
  • Restent locaux sur la machine où le Service est exécuté.
  • Ne sont jamais transmis à des services externes.

6. Cookies et suivi

Le Service ne définit aucun cookie, ne fait aucun suivi analytique et n'utilise aucun pixel de suivi. Ce site statique (GitHub Pages) n'utilise pas de cookies.

7. Sécurité

Nous mettons en place des mesures de sécurité pour protéger les données en transit :

  • Toutes les communications avec les API tierces se font via HTTPS.
  • Les entrées utilisateur sont validées via Pydantic.
  • Les timeouts HTTP sont configurés pour éviter les connexions pendantes.
  • Le Service ne permet aucune exécution de code arbitraire.

8. Droits des utilisateurs

Puisque le Service ne collecte pas de données personnelles, il n'y a pas de données à consulter, modifier ou supprimer. Si vous souhaitez supprimer des données créées via le Service sur des plateformes tierces (publications, issues, etc.), veuillez le faire directement sur la plateforme concernée.

9. Mineurs

Le Service n'est pas destiné aux personnes de moins de 16 ans. Nous ne collectons pas sciemment de données de mineurs.

10. Modifications

Nous nous réservons le droit de modifier la présente politique à tout moment. Les modifications prennent effet dès leur publication sur cette page. La date de dernière mise à jour est indiquée en haut du document.

11. Contact

Pour toute question relative à la confidentialité, veuillez ouvrir une issue sur le dépôt GitHub du projet.
